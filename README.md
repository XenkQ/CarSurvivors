# Car Survivors
Game like vampire surviviors but in 3D and you are a car.

# Description
The apocalypse has arrived 🧟‍♀️🧟‍♂️. Your only task is to survive. Fortunately, you are a professional driver-assassin who knows how to cope with life 🚗🩸.

# Current version
Original creators of this game with new members wanted to built something greater upon it so it will would be fun to play 🎮.
Game base: https://github.com/XenkQ/CarSurvivors
